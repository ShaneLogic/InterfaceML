What is InterfaceML?

InterfaceML is a toolkit for building and analyzing heterojunction interfaces for DFT calculations. It ships with a CLI, a Python API, and a Flask web UI.

Adsorbate Modeling

Build perovskite and fullerene interfaces with configurable terminations and layer gaps.

PbI / FAI / MAI Supercell auto Stacked adsorbates

Interface Builder

Match two materials with strain control, commensurate supercells, and Miller indices.

ZSL matching Bidirectional strain Report metrics

Layer Management

Fix layers for relaxation or split multi-layer stacks while preserving lattice data.

Selective dynamics Smart splitting CP2K ready

Density and DOS Tools

Compute delta density cubes and plot TDOS/PDOS overlays from CP2K outputs.

Delta rho TDOS + PDOS PNG export

Use Manual

Follow these steps to install, verify, and run your first workflow.

1. Install

Install dependencies and the editable package from the repo root.

pip install -r requirements.txt
pip install -e .

2. Verify

Confirm the core API and CLI are available.

python -c "from interfaceml.core import io, layering; print('InterfaceML import: OK')"
python build_heterojunctions/interface_builder.py --help

3. CLI Workflow

Build an adsorbate model, then fix the bottom layers for relaxation.

python build_heterojunctions/interface_builder.py \
    --adsorbate_mode \
    --base structures/perovskites/fapbi3-1.cif \
    --adsorbate structures/etl/C60-Ih.cif \
    --termination FAI \
    --distance 2.5 \
    --output my_interface.vasp

python build_heterojunctions/fix_interface_layers.py \
    --by_z_layers \
    --input my_interface.vasp \
    --n_fix_layers 3 \
    --output my_interface_fixed.vasp

4. Web Interface

Launch the interactive UI for uploads, parameters, and downloads.

python -m interfaceml.web.app

Docs load at /; the web app lives at /app.

5. Python API

Use the canonical API in interfaceml.core for scripting.

from interfaceml.core import io, layering

structure = io.load_structure("my_structure.vasp")
layers, _ = layering.split_layers_by_z(structure)
fixed = [i for layer in layers[:3] for i in layer]
fixed = layering.include_whole_molecules(structure, fixed)

selective = [
    (False, False, False) if i in fixed else (True, True, True)
    for i in range(len(structure))
]
io.write_poscar(structure, "output.vasp", selective_dynamics=selective)

Algorithm Overview

InterfaceML supports two generative architectures for molecular structure generation, each paired with a different sampling framework.

EGNN + DDPM

The Equivariant Graph Neural Network uses radial basis function (RBF) encoding of inter-atomic distances, message-passing with soft attention, and equivariant coordinate updates. Paired with a Denoising Diffusion Probabilistic Model (cosine noise schedule, 1000 timesteps), it iteratively removes Gaussian noise to generate molecular geometries.

E(3) Equivariant Attention Cosine schedule DDIM sampling

PaiNN + Flow Matching

The Polarizable Atom Interaction Neural Network maintains separate scalar and vector channels, using sinc-basis radial filters and inner-product coupling to encode bond angles without explicit angular features. Paired with Flow Matching (linear interpolation, Euler ODE integration, ~50 steps), it learns a velocity field that transports noise to data.

Scalar + Vector Sinc basis ODE solver 50 steps

DDPM Framework

The forward process progressively corrupts data with Gaussian noise according to a cosine variance schedule. The reverse process learns to denoise, recovering clean structures step by step.

$$q(x_t | x_0) = \mathcal{N}\!\left(\sqrt{\bar\alpha_t}\, x_0,\; (1-\bar\alpha_t)I\right)$$

Cosine schedule: $\bar\alpha_t = \cos^2\!\left(\frac{t/T + s}{1+s}\cdot\frac{\pi}{2}\right)$ with $s=0.008$. DDIM acceleration uses a stride-based sub-sequence for faster sampling.

Flow Matching Framework

Instead of iterative denoising, flow matching learns a velocity field that defines a continuous trajectory from noise to data via an ODE.

$$x_t = (1-t)\,x_0 + t\,\xi, \quad v_\text{target} = \xi - x_0$$

The model predicts $v_\theta(x_t, t)$ and generation uses Euler integration: $x_{t+\Delta t} = x_t + \Delta t \cdot v_\theta(x_t, t)$.

Physics-Informed Loss Functions

Both architectures can be fine-tuned with physics losses that encourage chemically valid geometries. Each loss is weighted by a time-conditioned sigmoid that focuses enforcement on late (clean) timesteps:

$$\mathcal{L}_\text{total} = \mathcal{L}_\text{denoise} + \sum_i \lambda_i \cdot w(t) \cdot \mathcal{L}_i, \quad w(t) = \sigma\!\left(-15\!\left(\tfrac{t}{T} - 0.4\right)\right)$$

Bond Length Loss

Huber loss on predicted inter-atomic distances vs. ideal C-C bond length (1.45 A). Penalizes bonds that are too short or too long.

Sphericity Loss

Computed from eigenvalues of the gyration tensor. Penalizes deviation from a perfect sphere (ratio of smallest to largest eigenvalue).

Connectivity Loss

Smooth polynomial penalty on atom coordination numbers. Encourages exactly 3 neighbors per carbon (sp2 bonding).

Topology Loss

Ring-counting penalty for non-fullerene ring sizes. Encourages 5- and 6-membered rings (pentagons and hexagons). Disabled for large molecules (>70 atoms).

Mathematical Details

Full derivations and formulas for both model architectures, sampling frameworks, and physics loss functions.

EGNN Layer

Each layer computes edge messages, attention weights, node updates, and equivariant coordinate updates.

RBF encoding: $$\text{RBF}_k(d) = \exp\!\left(-\gamma_k (d - \mu_k)^2\right), \quad k=1,\ldots,K$$
Edge messages: $$m_{ij} = \phi_e\!\left(h_i,\, h_j,\, \text{RBF}(d_{ij})\right)$$
Attention: $$\alpha_{ij} = \text{softmax}_j\!\left(\frac{\phi_q(h_i)^T \phi_k(h_j)}{\sqrt{d_\text{model}}}\right)$$
Node update (with residual): $$h_i' = h_i + \phi_h\!\left(\sum_j \alpha_{ij}\, m_{ij}\right)$$
Coordinate update (equivariant): $$\Delta x_i = \sum_j \alpha_{ij}\,(x_i - x_j)\,\tanh\!\left(\text{MLP}(m_{ij})\right) \cdot e^{-d_{ij}^2/2}$$ $$x_i' = x_i + \Delta x_i$$

The coordinate update preserves E(3) equivariance because $x_i - x_j$ transforms covariantly under rotations and translations, and all scalar coefficients depend only on invariant quantities (distances, node features).

PaiNN Layer

PaiNN maintains scalar features $s_i \in \mathbb{R}^F$ and vector features $V_i \in \mathbb{R}^{F \times 3}$ per atom.

Sinc basis with cosine cutoff: $$f_n(d) = \frac{\sin(n\pi d/r_c)}{d} \cdot \frac{1}{2}\left(\cos\!\left(\frac{\pi d}{r_c}\right) + 1\right)$$
Filter network (3 channels): $$W_s,\, W_{vv},\, W_{vs} = \text{split}\!\left(\text{MLP}(f(d_{ij}))\right) \in \mathbb{R}^{3F}$$
Message passing: $$\Delta s_i = \sum_j W_s \odot s_j, \quad \Delta V_i = \sum_j W_{vv} \odot V_j + W_{vs} \odot s_j \cdot \hat{r}_{ij}$$
Update module (inner product encodes angles): $$a_{ss},\, a_{sv},\, a_{vv} = \text{MLP}(s_i)$$ $$\Delta s_i^{\text{upd}} = a_{ss} + a_{sv} \cdot \langle U V_i,\, V V_i \rangle$$ $$\Delta V_i^{\text{upd}} = a_{vv} \cdot U V_i$$

The inner product $\langle UV_i, VV_i\rangle$ captures angular information between different vector channels without explicitly computing angles, maintaining O(3) equivariance for vectors and invariance for scalars.

DDPM Sampling

Cosine beta schedule: $$\bar\alpha_t = \cos^2\!\left(\frac{t/T + s}{1+s}\cdot\frac{\pi}{2}\right), \quad s=0.008$$ $$\beta_t = 1 - \frac{\bar\alpha_t}{\bar\alpha_{t-1}}$$
Posterior mean (reverse step): $$\mu_\theta(x_t, t) = \frac{1}{\sqrt{\alpha_t}}\left(x_t - \frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\,\epsilon_\theta(x_t, t)\right)$$
DDIM (accelerated sampling with $\eta$ parameter): $$x_{t-1} = \sqrt{\bar\alpha_{t-1}}\,\hat{x}_0 + \sqrt{1-\bar\alpha_{t-1}-\sigma_t^2}\,\epsilon_\theta(x_t,t) + \sigma_t\,\epsilon$$ $$\sigma_t = \eta\sqrt{\frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}}\sqrt{\beta_t}$$

When $\eta=0$ DDIM is deterministic; $\eta=1$ recovers DDPM. Sub-sequences of the full schedule allow generation in fewer steps.

Flow Matching

Linear interpolation (optimal transport path): $$x_t = (1-t)\,x_1 + t\,x_0, \quad t \in [0, 1]$$ $$v_\text{target}(x_t, t) = x_0 - x_1$$
Training objective: $$\mathcal{L}_\text{FM} = \mathbb{E}_{t,x_0,x_1}\left[\|v_\theta(x_t, t) - v_\text{target}\|^2\right]$$
Euler integration (generation): $$x_{t+\Delta t} = x_t + \Delta t \cdot v_\theta(x_t, t), \quad \Delta t = 1/N_\text{steps}$$

Flow matching avoids the variance explosion issues of DDPM at high noise levels and typically converges in 50 steps vs. 1000 for DDPM.

Physics Loss Functions

Time-conditioned weighting: $$w(t) = \sigma\!\left(-15\!\left(\frac{t}{T} - 0.4\right)\right) = \frac{1}{1+e^{15(t/T - 0.4)}}$$
Bond length loss (Huber): $$\mathcal{L}_\text{bond} = \frac{1}{|\mathcal{E}|}\sum_{(i,j)\in\mathcal{E}} H_\delta(d_{ij} - d_\text{ideal}), \quad d_\text{ideal}=1.45\text{ A}$$
Sphericity loss (gyration tensor): $$S_{ab} = \frac{1}{N}\sum_i (r_{i,a}-\bar{r}_a)(r_{i,b}-\bar{r}_b)$$ $$\mathcal{L}_\text{sphere} = 1 - \frac{\lambda_\text{min}}{\lambda_\text{max}}$$
Connectivity loss (smooth polynomial): $$c_i = \sum_j p(d_{ij}), \quad p(d) = \begin{cases} 1 & d \le d_1 \\ \text{smooth falloff} & d_1 < d < d_2 \\ 0 & d \ge d_2 \end{cases}$$ $$\mathcal{L}_\text{conn} = \frac{1}{N}\sum_i (c_i - 3)^2$$
Topology loss (ring counting): $$\mathcal{L}_\text{topo} = \sum_{k \notin \{5,6\}} n_k \cdot w_k$$

Training Details

EMA (Exponential Moving Average): $$p_\text{ema} := \alpha \cdot p_\text{ema} + (1-\alpha) \cdot p_\text{model}, \quad \alpha=0.999$$
Learning rate schedule (warmup + cosine decay): $$\text{lr}(t) = \begin{cases} \text{lr}_\text{max} \cdot t/T_\text{warm} & t < T_\text{warm} \\ \text{lr}_\text{min} + \frac{1}{2}(\text{lr}_\text{max}-\text{lr}_\text{min})\left(1+\cos\frac{\pi(t-T_\text{warm})}{T_\text{total}-T_\text{warm}}\right) & t \ge T_\text{warm}\end{cases}$$
Biased timestep sampling: $$t \sim \text{Beta}(a, b) \cdot T, \quad a=1.5,\, b=1.0$$

EMA weights are used by default at generation time. The biased sampling focuses training on noisier timesteps where the model needs the most learning signal.

API Introduction

InterfaceML exposes both a Python API and a REST API from the web server.

Python API (Core)

Canonical modules live in interfaceml.core.

  • interfaceml.core.io - structure I/O for VASP, CIF, XYZ
  • interfaceml.core.layering - layer detection and fixes
  • interfaceml.core.splitting - smart splitting utilities
from interfaceml.core import io, splitting

structure = io.load_structure("trilayer.vasp")
layers = splitting.split_structure_into_layers(structure, n_interfaces=2)
for i, layer in enumerate(layers, 1):
    io.write_poscar(layer, f"layer{i}.vasp")

Web API (REST)

Start the server with python -m interfaceml.web.app and call endpoints below.

Method Endpoint Description Notes
GET /api/health Health check and module availability. Returns version and core status.
POST /api/upload Upload structure or DOS files. Multipart form with file and file_type.
GET /api/download/<filename> Download generated outputs. Files live in the server upload folder.
POST /api/build-interface Build heterojunction interfaces. Placeholder: returns 501.
POST /api/build-adsorbate Build adsorbate models. Placeholder: returns 501.
POST /api/fix-layers Add selective dynamics to layers. Uses structure_file and layer params.
POST /api/split-layers Split structures into layer files. Returns layer metadata + download URLs.
POST /api/pdos-layers Create CP2K PDOS blocks per layer. Returns indices and PDOS block text.
POST /api/plot-dos Render TDOS + PDOS to PNG. Returns image_url for download.
POST /api/ai/generate Generate fullerene structures. Requires AI module availability.
POST /api/ai/evaluate Evaluate generated structures. Returns metrics and plot URL.
GET /api/ai/info Fetch AI model info. Returns model metadata when ready.
